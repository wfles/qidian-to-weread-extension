# 起点 -> 微信读书助手

一个 Chrome 浏览器插件，帮助你在起点中文网页面快速跳转到微信读书阅读同一本书。

## 功能特性

- 自动识别起点中文网的小说详情页
- 自动获取书名和作者信息
- 在微信读书中搜索该书
- 如果找到匹配的书籍（书名和作者都匹配），会在页面上添加「去微信读书阅读」按钮
- 点击按钮直接跳转到微信读书对应书籍页面

## 安装方法

### 方法一：开发者模式安装（推荐）

1. 下载或克隆此项目到本地

2. 打开 Chrome 浏览器，访问 `chrome://extensions/`

3. 打开右上角的「开发者模式」开关

4. 点击「加载已解压的扩展程序」

5. 选择项目文件夹 `qidian-to-weread-extension`

6. 插件安装完成！

### 方法二：打包安装

1. 在 `chrome://extensions/` 页面点击「打包扩展程序」

2. 选择项目文件夹

3. 生成的 `.crx` 文件可以分享给其他人安装

## 使用方法

1. 安装插件后，访问起点中文网的任意书籍详情页，例如：
   - https://www.qidian.com/book/1042342714/

2. 插件会自动：
   - 获取书名和作者信息
   - 在微信读书中搜索
   - 如果找到匹配的书籍，会在页面操作区域添加「去微信读书阅读」按钮

3. 点击按钮即可跳转到微信读书阅读该书

## 插件文件说明

- `manifest.json` - 插件配置文件
- `content.js` - 内容脚本，在起点页面运行，负责获取书籍信息和插入按钮
- `background.js` - 后台服务，处理跨域请求和消息通信
- `styles.css` - 按钮样式

## 技术实现

- 使用 Chrome Extension Manifest V3
- 通过 Content Script 从起点页面提取书籍信息
- 调用微信读书内部搜索API进行匹配
- 动态创建和插入DOM元素
- 处理CORS跨域问题

## 注意事项

1. 插件仅在起点中文网的书籍详情页运行
2. 只有当书名和作者都完全匹配时才会显示按钮
3. 需要网络连接才能搜索微信读书
4. 微信读书的API可能会变化，如果搜索失败可能需要更新插件

## 调试

1. 按 F12 打开浏览器开发者工具
2. 查看 Console 标签，可以看到插件的运行日志
3. 所有日志都以 `[起点助手]` 开头，方便识别

## 常见问题

**Q: 为什么没有显示按钮？**
A: 可能原因：
- 微信读书未找到该书（书名或作者不匹配）
- 页面结构变化导致无法获取书籍信息
- 网络请求失败

**Q: 如何查看插件运行状态？**
A: 打开浏览器控制台（F12），查看以 `[起点助手]` 开头的日志信息。

**Q: 支持其他小说网站吗？**
A: 目前仅支持起点中文网，未来可能会添加更多网站支持。
